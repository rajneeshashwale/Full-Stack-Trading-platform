Full Stack Trading Platform
Project Overview

Full Stack Trading Platform is a modern stock trading web application inspired by platforms like Zerodha. The platform allows users to manage investments, track portfolios, monitor market trends, and perform stock trading operations through a secure and responsive interface.

This project was developed to demonstrate real-world implementation of full stack web development concepts including frontend design, backend APIs, authentication systems, database management, and trading workflow architecture.

Installation
# Clone Repository
git clone <repository-url>

# Open Project Folder
cd full-stack-trading-platform

# Install Dependencies
npm install

# Install Backend Dependencies
cd backend
npm install

# Run Frontend
npm run dev

# Run Backend
npm start
Environment Variables

Create a .env file:

PORT=5000
MONGO_URI=your_database_url
JWT_SECRET=your_secret_key
